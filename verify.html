Verify Sentari evidence

Opens a signed evidence pack, SBOM or VEX and checks it on this machine. Nothing is uploaded — this page makes no network requests at all.

Drop the file here or click to choose · .json or .zip, or select all the files from an extracted pack

A third independent implementation of the open Sentari evidence-pack specification, alongside the Python and Go reference verifiers in the same repository. All three are held to one published verdict table and agree on every committed conformance vector. Apache‑2.0 — read the source of this file, check it, reimplement it.

Needs no network and no installation. To confirm you are running the published verifier and not an altered copy, compare this file’s SHA‑256 against verify.html.sha256 in the repository — on macOS or Linux: shasum -a 256 verify.html
